# General Instructions

  > **For All Cases:** The input function must be in standard form, meaning it should be equated to zero. For example, if the given equation is x^3-x^2=2, the input function should be x^3-x^2-2

> **In Method of Successive Substitution:** The user has the option to type the given function, but they are required to simplify the function themselves for this method to proceed.

  > **For Matrices (Gaussian, Gauss-Jordan, Jacobi):** First, select the dimension of the matrix. The user input should not be a variable, it should be consisting of coefficients and constants

# Numerical Methods Included

**Finding the Area Under the Curve**
- Trapezoidal Rule
- Simpson's Rule

**Finding the Value of the Unknown**
- Bisection Method
- Method of Successive Substitution (M.O.S.S.)
- Newton-Raphson Method

**Finding Multiple Variable**
- Linear with Approximate Value:
    - Jacobi Method
- Linear with Approximate Value:
    - Gaussian
    - Gauss-Jordan
- Non-Linear:
    - Newton's Non-Linear Method
